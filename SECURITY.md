## Reportando Vulnerabilidades

Levamos a segurança a sério. Se você descobrir uma vulnerabilidade de segurança, por favor siga estas diretrizes:

### ⚠️ NÃO crie uma issue pública

Vulnerabilidades de segurança devem ser reportadas de forma privada para proteger nossos usuários.

### 📧 Como Reportar

Envie um e-mail para: **security@agendafacil.pro**

Inclua no e-mail:
- Descrição detalhada da vulnerabilidade
- Passos para reproduzir
- Impacto potencial
- Sugestões de mitigação (se houver)
- Seu nome/handle para atribuição de crédito (opcional)

### ⏱️ Tempo de Resposta

- **Confirmação de recebimento:** Dentro de 48 horas
- **Avaliação inicial:** Dentro de 7 dias
- **Resolução:** Dependendo da severidade, de 14 a 90 dias

### 🏆 Programa de Reconhecimento

Agradecemos pesquisadores de segurança que reportam vulnerabilidades de forma responsável. Créditos serão dados no CHANGELOG e em nossa página de agradecimentos.

## Práticas de Segurança

- Todas as dependências são verificadas automaticamente via Dependabot
- Secrets são gerenciados via GitHub Secrets
- Código é revisado antes de merge
- Dependências são mantidas atualizadas
